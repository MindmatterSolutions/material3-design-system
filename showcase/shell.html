Material Web, themed

Google's official @material/web components, the Expressive md-gb-* set included, wearing this repo's theme. No component was restyled: they read Material's system roles, and the theme supplies them. Pick an accent and every component follows.

Components: @material/web (Apache-2.0), bundled into components/material-web.js. Theme: index.css + components/theme-bridge.css. Everything is self-hosted — no third-party request at runtime.
