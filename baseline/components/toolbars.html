Toolbars replace the bottom app bar. The floating toolbar is a pill at level-3 elevation that can sit beside a FAB, run vertically, and switch to the vibrant (primary-container) color for a stronger voice. The docked toolbar spans the window edge at 64dp and holds global actions; it can host a centered filled icon button in place of a FAB.
