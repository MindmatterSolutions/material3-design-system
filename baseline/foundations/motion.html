Shape morph on press

Motion is physics: a spring is a damping ratio and a stiffness, not a duration. Spatial springs move position, size and shape and may overshoot; effects springs change color and opacity and never do. The expressive scheme (damping 0.6–0.8) is the default; the standard scheme (0.9) is for calmer, utilitarian products. Each token is a CSS linear() curve with a matching -duration. The lanes above loop each curve stretched to 1.8s so the shape is visible.
