Shape library

Three new corner steps (large-increased, extra-large-increased, extra-extra-large) for bigger, softer containers. The abstract shapes are for emphasis — avatars, image crops, loading indicators, a hero moment — never for text containers. Each is also a clip-path token (var(--md-shape-path-cookie-9)) with a shared point count, so any two morph when a clip-path transitions between them.
