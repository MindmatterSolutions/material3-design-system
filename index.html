Material 3 Expressive

A theme layer that re-points one semantic token set at Material 3's system roles. Colour is Material's dark scheme generated from the seed #ff7a1a with fidelity, so the accent stays saturated rather than becoming a pastel. Pick an accent — the ground does not move.

Accent roles

The four key colours and their containers. Only these change with the accent picker; the neutrals below are set once and no accent restates them.

Neutral roles

One near-grey palette (hue ~300, chroma ~2) — the tone m3.material.io is itself drawn in. Surfaces, the ink on them and the outlines all come from here, which is why choosing an accent recolours the accent roles and leaves the page's ground exactly as it is.

Type scale

Roboto Flex is the Expressive sans, carrying every role from display to label; the variable wdth axis is what the display and card-title roles widen to 110. The scale was moved onto Material's steps — nothing is set below 11px, Material's floor for anything read.

Headings

Sentence case, heavier, larger. This is most of what makes a page read as Material, and it is typography only — no layout moves.

Shape

Expressive adds the -increased steps. Big soft containers, fully round controls — a chip takes the 8px step instead of a pill, so a chip reads differently from a button.

Motion

Expressive motion is springs, approximated here as cubic-béziers. The spatial curves overshoot — that is the point of them — and are only for transform and size. The effects curves do not overshoot, and they are the ones for colour and opacity.

The semantic layer

No component knows this theme exists. It re-points the same contract the base tokens declare, so deleting the one @import puts the system back exactly as it was.

Status hues

Deliberately not remapped. Material has only error among these, and no role at all for "pending" or "review" — these carry meaning rather than brand, so they stay put under every accent.
